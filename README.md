# 🎙️ Voice Search & Note Taker App

> A modern, minimalist web-based speech-to-text application built with vanilla HTML5, CSS3, and JavaScript, leveraging the native Web Speech API.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black) ![Status](https://img.shields.io/badge/Status-Completed-success)

---

## ✨ Features

* **Real-time Speech Recognition:** Instantly converts spoken words into text in real-time using the browser's built-in `Web Speech API`.
* **Modern SaaS Dark Theme:** Styled with a clean, eye-friendly dark color palette utilizing custom CSS variables (`:root`) and smooth micro-interactions.
* **Clipboard Integration:** Copy your transcribed text instantly to the clipboard with a single click and visual confirmation feedback.
* **Text File Export:** Download your notes instantly as a `.txt` file with an automatically generated date-stamped filename.
* **Quick Management:** Easily clear the workspace with a confirmation prompt.

---

## 🛠️ Built With

* **HTML5:** Semantic layout and structure.
* **CSS3:** Custom properties, Flexbox layout, grid alignment, and hover transitions.
* **JavaScript (ES6+):** DOM manipulation, event listeners, Blob creation, and Web Speech API handling.
* **FontAwesome (v6.7.2):** Scalable vector icons for intuitive UI buttons.
